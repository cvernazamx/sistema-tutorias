# UEES | Diseño de Software | UCOM0310
## Semana 4 – Taller práctico: Patrones aplicados

Proyecto base deliberadamente acoplado para practicar:

- Adapter
- Facade
- Strategy
- Observer
- UML
- Git
- justificación técnica para Ae3

## Regla principal

No empieces creando patrones.

Primero:
1. ejecuta;
2. observa;
3. identifica qué cambia;
4. señala el acoplamiento;
5. selecciona un patrón solo si resuelve esa fuerza.

## Comandos

```bash
mvn clean compile
mvn clean test
mvn exec:java
```
