# AE2 | Implementacion Comparativa de Patrones de Diseno
**Materia:** Diseno de Software (UCOM0310) - Semana 3
**Estudiante:** Christian Fernando Vernaza Vernaza
**Tecnologias:** Java 21, Maven, PlantUML, macOS

## Estructura del Modulo
- `src/main/java/.../factory/`: Factory Method (Notificador, Creators y variante Teams).
- `src/main/java/.../builder/`: Builder (Reserva inmutable, Fluent API y validaciones).
- `docs/`: Diagramas UML (factory-method.puml y builder.puml).

## Compilacion y Ejecucion
```bash
mvn clean compile
mvn exec:java -Dexec.mainClass="edu.uees.patrones.App"
```
